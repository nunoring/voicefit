# commerce_pack 테스트 입력 샘플

내일 `/generate` → 커머스 패키지에 바로 붙여넣을 수 있는 샘플 3개.
실제 쿠팡 URL은 없으므로 URL 칸은 비워두거나 아무 텍스트를 넣어도 된다.

---

## 샘플 1 — 신혼/자취 생활템

**상품명**: 천연 수세미 5개 세트
**가격**: 6900
**상품 URL**: (비워도 됨 — 나중에 실제 파트너스 링크로 교체)
**usage_basis**: `사용 안 함` (정보성 큐레이션)

**입력 메모 (상품 설명란)**: 야자 껍질로 만든 천연 수세미. 기름기 제거에 좋고 미세플라스틱 걱정 없음. 습기에 약해서 사용 후 잘 건조해야 오래 씀.

---

## 샘플 2 — AI 작업환경 장비

**상품명**: USB-C 7포트 허브 (4K HDMI + 카드리더 + PD100W)
**가격**: 34900
**상품 URL**: (비워도 됨)
**usage_basis**: `직접 사용함`

**입력 메모 (상품 설명란)**: 맥북에 꽂아서 모니터 + 외장 SSD + 카드리더 동시에 쓰는 중. 발열이 약간 있지만 실사용에 지장은 없음. PD 충전은 60W 이상으로 제대로 들어옴.

---

## 샘플 3 — 집정리/청소템

**상품명**: 폴리프로필렌 서랍형 정리함 4단 세트
**가격**: 18500
**상품 URL**: (비워도 됨)
**usage_basis**: `정보성 큐레이션`

**입력 메모 (상품 설명란)**: 반투명 소재라 내용물 파악이 쉬움. 서랍 높이가 낮아서 얕은 물건(속옷, 양말, 문구류) 정리에 적합. 깊은 물건(책, 큰 옷)은 안 맞음.

---

## 테스트 순서 (10분 버전)

1. `/generate` 접속
2. "🧪 커머스 패키지" 선택
3. 위 샘플 중 하나 복붙 (상품명 + 가격 + 메모)
4. usage_basis 선택
5. "생성하기" 클릭
6. mock 모드라면 바로 결과 나옴 (`[mock 모드 ...]` 문구 확인)
7. "검수로 넘기기" → `/review`
8. 정책 감사 자동 실행 확인 (좌측 체크리스트 아래)
9. "섹션별 복사" 버튼 9개 중 "블로그만" + "릴스 캡션" 눌러서 텍스트 확인
10. 완료

---

## mock 모드 설정 (먼저 확인)

`.env.local`에 이 줄이 있는지 확인:
```
COMMERCE_PACK_MOCK=1
```

없으면 추가 후 dev 서버 재시작 (`npm run dev`). 이 줄 없으면 실제 Claude API 호출 + 비용 발생.

mock 끄려면: `COMMERCE_PACK_MOCK=1` 줄을 삭제하거나 `COMMERCE_PACK_MOCK=0`으로 변경 → dev 서버 재시작.
