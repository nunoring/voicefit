# commerce_pack 샘플 출력물

실제 Anthropic API를 호출하지 않고(비용·DB 부작용 방지 목적, [BLOCKED_NOTES.md](../BLOCKED_NOTES.md) 참조)
`COMMERCE_PACK_RULES` + `buildCommercePackPrompt`가 만들어내야 할 출력 형태를 손으로 작성한 예시다.
실제 생성 결과는 이 구조(8섹션 고정 순서·제목, 고지 위치, 말투)를 따라야 한다.

## 샘플 1 — 신혼/자취 생활템 (정보성 큐레이션, `usage_basis: curation`)

입력 가정:
- 상품명: 압축 다용도 수납백 5종 세트
- 가격: 19,900원
- URL: (쿠팡 파트너스 링크, 예시용 더미)
- 사진: 없음 → 쿠팡 공식 이미지 자동 사용
- 사용 여부: **사용 안 함 (정보성 큐레이션)**

```markdown
## 블로그 글

# 신혼집 옷장 터지기 직전이면 — 압축 수납백 5종 세트 (19,900원)

(이 글은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.)

이사·신혼 준비하면서 수납 고민 한 번쯤 다들 해보셨을 거예요.
저도 직접 써본 건 아니고, 자취·신혼 커뮤니티에서 자주 언급되길래 스펙 위주로 정리해봤어요.

가격은 19,900원, 5종 세트 구성이에요.
부피 큰 이불·겨울옷을 압축해서 옷장 공간을 줄이는 용도로 쓰는 제품이고요.

정확한 압축률이나 재질 두께 같은 디테일은 판매 페이지에 표기된 정보 이상으로는 확인이 안 돼서,
여기서는 더 보태지 않을게요. 궁금하시면 상세페이지에서 직접 스펙 확인하시는 걸 추천해요.

이런 분들께 맞을 것 같아요: 신혼집 옷장 정리 막막한 분, 계절옷 보관 공간 부족한 자취생.

## 쇼츠 대본

[0-3초] (이 영상은 쿠팡 파트너스 제휴 고지 포함) 신혼집 옷장 터지기 직전이라면 이거.
[3-8초] 5종 세트 압축 수납백, 가격은 19,900원.
[8-12초] 계절옷·이불 압축해서 옷장 공간 확보용.
[12-15초] 자세한 스펙은 설명란 링크에서 확인하세요.

## 쇼츠 설명란

(쿠팡 파트너스 활동의 일환으로 일정액의 수수료를 제공받습니다)
신혼/자취 옷장 정리용 압축 수납백 5종 세트, 19,900원. 계절옷·이불 보관용으로 찾아보시는 분들 많아서 정리했어요.
#신혼살림 #자취템 #수납정리 #옷장정리 #생활템

## 릴스 캡션

#광고 (쿠팡 파트너스 제휴 고지)
신혼집 옷장 터지기 직전 분들 주목 👀
압축 수납백 5종, 19,900원
계절옷·이불 보관용으로 찾아보시는 분 많더라구요
#신혼살림 #자취템 #수납정리

## 고정댓글 / CTA

1. (정보 강조형) 가격·구성 더 자세히 보고 싶으면 프로필 링크 확인하세요.
2. (공감형) 옷장 정리 고민 많으셨던 분들, 댓글로 어떤 수납템 쓰시는지 공유해주세요.
3. (담백한 행동유도형) 필요하신 분은 링크에서 가격·구성 확인해보세요.

## 제휴 고지

이 콘텐츠(블로그·쇼츠·릴스 포함)는 쿠팡 파트너스 활동의 일환으로 작성되었으며,
이를 통해 발생하는 구매에 대해 일정액의 수수료를 제공받습니다.

## 실험 가설

가설 1: "신혼/자취" 키워드를 제목에 넣으면 일반 "수납템" 제목보다 블로그 체류시간이 길 것이다.
가설 2: 릴스 캡션 첫 줄 고지(#광고)가 있어도 저장수에는 큰 영향이 없을 것이다.
측정 지표: 블로그 평균 체류시간, 릴스 저장수·공유수, 쇼츠 끝까지 시청률.
판단 기준: 2주 내 동일 카테고리 직전 글 대비 체류시간 +20% 이상이면 성공, 아니면 제목 톤 재검토.

## 발행 전 체크리스트

- [ ] 제휴 고지가 블로그/쇼츠설명/릴스캡션 각 상단에 노출됐는가
- [ ] 효능·압축률·할인율 등 상품정보에 없는 수치를 지어내지 않았는가
- [ ] "직접 써보니" 같은 사용 후기 표현이 들어가지 않았는가 (정보성 큐레이션이므로)
- [ ] 가격·구성 정보가 입력값과 일치하는가
- [ ] AI 생성 이미지·가상인물을 썼다면 표시했는가 (이 샘플은 쿠팡 공식 이미지라 해당 없음)
```

## 샘플 2 — AI 작업 환경 장비 (직접 사용, `usage_basis: used`)

입력 가정:
- 상품명: 무선 트랙볼 마우스
- 가격: 89,000원
- 사용 메모: "손목 안 아프려고 샀음. 책상 위 공간 덜 차지함. 충전은 USB-C, 완충 한 번이면 며칠 감"
- 사용 여부: **직접 사용함**

```markdown
## 블로그 글

# 손목 아파서 바꾼 무선 트랙볼 마우스 — 3주 써본 후기

(이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.)

하루 종일 마우스 잡고 작업하다 보니 손목이 슬슬 아파오더라구요.
그래서 바꾼 게 이 무선 트랙볼 마우스, 가격은 89,000원이에요.

직접 써보니 일단 책상 위 공간을 덜 차지해서 그게 제일 마음에 들었어요.
손목을 움직이는 대신 엄지로 볼을 굴리는 방식이라 확실히 손목 부담이 줄긴 했어요.

충전은 USB-C 방식이고, 완충 한 번이면 며칠은 가더라구요. 매일 충전 안 해도 되는 게 편해요.

다만 이건 제 개인 경험이라 손목 통증 원인이나 개선 효과를 일반화하긴 어려워요.
손목이 불편하신 분들은 한 번쯤 트랙볼 방식 고려해보셔도 좋을 것 같아요.

## 쇼츠 대본

[0-3초] (쿠팡 파트너스 제휴 고지 포함) 손목 아파서 마우스 바꿨습니다.
[3-8초] 무선 트랙볼, 3주째 직접 쓰는 중. 책상 공간 덜 차지함.
[8-12초] 완충 한 번이면 며칠 감. 가격은 89,000원.
[12-15초] 손목 불편하신 분들 후기 댓글로 더 알려드릴게요.

## 쇼츠 설명란

(쿠팡 파트너스 활동의 일환으로 일정액의 수수료를 제공받습니다)
손목 통증 때문에 바꾼 무선 트랙볼 마우스, 3주 직접 사용 후기입니다. 가격 89,000원.
#트랙볼마우스 #손목보호 #재택근무템 #작업환경 #무선마우스

## 릴스 캡션

#광고 (쿠팡 파트너스 제휴 고지)
손목 아파서 바꾼 마우스, 3주 써본 솔직 후기 ✋
책상 공간 덜 차지 + 완충 한 번에 며칠
#작업환경 #트랙볼마우스 #재택근무

## 고정댓글 / CTA

1. (정보 강조형) 스펙·가격 더 궁금하면 프로필 링크 확인하세요.
2. (공감형) 손목 통증 때문에 마우스 바꾸신 분 계시면 어떤 거 쓰시는지 댓글로 알려주세요.
3. (담백한 행동유도형) 같은 고민 있으신 분은 링크에서 확인해보세요.

## 제휴 고지

이 콘텐츠(블로그·쇼츠·릴스 포함)는 쿠팡 파트너스 활동의 일환으로 작성되었으며,
이를 통해 발생하는 구매에 대해 일정액의 수수료를 제공받습니다.

## 실험 가설

가설 1: "직접 써본 후기"임을 명시한 제목이 정보성 큐레이션 글보다 댓글 전환율이 높을 것이다.
가설 2: 쇼츠 설명란 고지 위치(첫 줄)가 클릭률에 부정적 영향을 주지 않을 것이다.
측정 지표: 블로그 댓글 수, 쇼츠 클릭률(설명란 링크 클릭), 릴스 저장수.
판단 기준: 동일 카테고리 직전 글 대비 댓글 수 2배 이상이면 성공, 1배 미만이면 후기 디테일 보강 필요.

## 발행 전 체크리스트

- [ ] 제휴 고지가 블로그/쇼츠설명/릴스캡션 각 상단에 노출됐는가
- [ ] "직접 써보니" 표현이 실제 사용 메모(usage_basis: used)와 일치하는가
- [ ] 메모에 없는 효능(예: "손목 통증 완치")을 지어내지 않았는가
- [ ] 가격 정보가 입력값과 일치하는가
- [ ] AI 생성 이미지·가상인물을 썼다면 표시했는가 (이 샘플은 직접 촬영 가정이라 해당 없음)
```
