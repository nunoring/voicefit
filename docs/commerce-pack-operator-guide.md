# commerce_pack 운영 가이드

VoiceFit `커머스 패키지` 모드로 "AI 커머스 콘텐츠 실험"을 돌릴 때 쓰는 운영 문서.
실제 게시는 항상 사람이 검수 후 수동으로 한다 — 이 앱은 초안 생성까지만 자동화한다.

---

## ⚠️ 먼저: 실업급여 수급 중이면 고용센터 확인부터

이 문서는 콘텐츠 운영 가이드이지 법률·노무 자문이 아니다.
**실업급여 수급 중에 블로그·쇼츠·릴스를 실제로 게시하거나 수익화(어필리에이트 클릭 발생 포함)하기 전에,
반드시 관할 고용센터에 "이 활동이 구직활동 의무·소득신고 의무에 저촉되는지" 직접 확인할 것.**
이 앱/문서는 그 판단을 대신해주지 않는다. 초안만 만들어두고 실제 게시는 고용센터 확인 후로 미루는 것을 기본값으로 한다.

---

## 30일 실험 루틴

상품 1개당 사이클이 아니라 "30일 동안 몇 개를 실험하느냐"가 핵심. 콘텐츠 퀄리티보다 사이클 수를 먼저 확보한다.

| 주차 | 목표 | 산출물 |
|---|---|---|
| 1주차 | 상품 수집 기준 확정 + 첫 3개 패키지 생성·검수 | commerce_pack 3개 (미게시, 초안만) |
| 2주차 | 1주차 중 통과한 것만 실제 게시 시작 (고용센터 확인 후) | 게시 1~2개 + 반응 관찰 |
| 3주차 | 반응 좋은 포맷(블로그/쇼츠/릴스 중 어디가 먹히는지) 파악, 가설 검증 | 실험 가설 결과 기록 |
| 4주차 | GO/KILL 판단, 다음 30일 방향 결정 | 회고 1페이지 |

원칙: 한 상품에 오래 매달리지 않는다. 검수에서 한 번 막히면(허위 주장·고지 누락 등) 다음 상품으로 넘어가고,
막힌 이유는 `BLOCKED_NOTES.md` 같은 별도 기록에 남겨 같은 실수 반복하지 않는다.

## 상품 수집 기준

다음 조건을 모두 만족하는 상품만 입력한다:

1. **쿠팡 파트너스에서 검색 가능한 상품** — 공식 이미지·가격을 자동으로 가져올 수 있어야 함 (수동 입력도 가능하지만 느림).
2. **효능/성능 주장이 단순한 상품 우선** — 의료기기·건강기능식품처럼 표시광고법 리스크 큰 카테고리는 1순위에서 제외.
3. **가격이 명확한 상품** — "문의" 가격, 변동 심한 타임세일 상품은 피한다 (지어내기 유혹 방지).
4. **직접 써본 상품 vs 정보성 큐레이션 상품을 미리 구분** — 입력 시 `usage_basis`를 정직하게 고른다. 안 써본 상품을 "써봄"으로 체크하지 않는다.
5. **신혼/자취 생활템, AI 작업환경 장비 등 본인이 실제 맥락을 아는 카테고리부터** — 메모가 구체적일수록 AI가 지어낼 필요가 줄어듬.

## 발행 전 체크리스트 (앱 내 체크리스트와 동일 — 사람이 직접 확인)

- [ ] 제휴 고지가 블로그·쇼츠설명·릴스캡션 각 상단(첫 부분)에 노출되는가
- [ ] 직접 사용하지 않은 상품을 사용 후기처럼 쓰지 않았는가 (`usage_basis` 확인)
- [ ] 효능·가격·할인율·수익 등 입력에 없는 정보를 지어내지 않았는가
- [ ] 유튜브 설명란·인스타 캡션에도 고지가 포함됐는가
- [ ] AI 생성 이미지·가상인물을 썼다면 표시했는가
- [ ] 발행 전 사람이 최종 검수했는가 — 이 체크리스트 자체가 그 기록

추가로 게시 직전에만 확인:
- [ ] 실업급여 수급 중이라면 고용센터 확인을 마쳤는가
- [ ] 네이버 블로그에 쿠팡 링크를 직접 넣지 않았는가 (정책 미확인 상태 — 기본 금지)

## 채널별 주의사항

**블로그 (티스토리/워드프레스)**
- 고지는 제목 바로 아래, 첫 문단에. 본문 맨 아래에만 넣지 않는다.
- 네이버 블로그는 쿠팡 링크 직접 삽입 금지 기본값 유지 (정책 확인 전).

**유튜브 쇼츠**
- 설명란 첫 줄에 고지 문구 필수. 대본은 20~30초 분량 — 과장 후킹 금지, 정보 위주.
- 영상 자체에 "제공받음/제휴" 같은 표시가 화면에도 보이면 더 안전 (텍스트 오버레이 등, 이 앱 범위 밖이지만 권장).

**인스타 릴스**
- 캡션 첫 줄에 `#광고` 또는 고지 문구. 해시태그 5개 이내로 제한해 스팸처럼 안 보이게.
- 가상 인물·AI 생성 이미지를 썼다면 캡션이나 영상 내 표시 필수.

**고정댓글/CTA**
- 가짜 희소성("품절임박", "오늘만") 금지. 정보 강조형/공감형/담백한 행동유도형 3종 정도면 충분.

## GO/KILL 기준 (30일 회고 시점)

**GO (계속 확장)**
- 게시한 패키지 중 절반 이상이 검수 체크리스트를 1차 통과 (재작성 없이)
- 최소 1개 채널(블로그/쇼츠/릴스 중)에서 댓글·저장·클릭 등 측정 가능한 반응 확인
- 실업급여/계정 정책 관련 문제 0건

**HOLD (포맷 조정 후 재시도)**
- 검수 통과율은 낮지만(50% 미만) 특정 한 채널에서만 반응이 좋은 경우 → 그 채널 위주로 좁혀서 재시도
- 고지 위치·표현 관련 지적이 반복되면 → 프롬프트 룰(`COMMERCE_PACK_RULES`) 보강 후 재시도

**KILL (중단)**
- 검수 단계에서 효능/가격 날조, 고지 누락 같은 컴플라이언스 이슈가 반복 발생 (구조적 문제로 판단)
- 실업급여 관련 고용센터 확인에서 제약 안내를 받은 경우 — 즉시 게시 중단, 초안 보관만
- 30일간 어떤 채널에서도 측정 가능한 반응이 전혀 없는 경우 — 포트폴리오 자산으로서의 가치만 남기고 본수익원 시도는 종료

## 부분 복사 활용법

검수 화면(`/review`) 발행 완료 후 "빠른 복사 — 채널별" 블록에서:
- **전체 복사**: 전체 마크다운 (보관용)
- **블로그만 복사**: 티스토리/워드프레스 에디터에 붙여넣기
- **쇼츠만 복사**: 대본 + 설명란을 한 번에 (유튜브 스튜디오용)
- **릴스만 복사**: 캡션만 (인스타 업로드 화면용)

채널별로 따로 복사해서 붙이면 다른 섹션 텍스트가 섞여 들어가는 실수를 줄일 수 있다.
